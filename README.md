# 兔子格式转换大师

兔子格式转换大师（RabbitCV）多格式文件转换工具。这个仓库只用来放安装包，不含源码。

## 下载

- 最新版安装包：[Releases](https://github.com/snokey1999/RabbitCV/releases/latest)（当前版本 v2.7.5）
- GitHub 会自动去掉资源文件名里的中文，所以安装包在页面里显示为 `RabbitCV-setup-2.7.5.exe`，下载后重命名不影响使用。

## 安装

双击安装包，按向导提示操作。向导里可以按需勾选 FFmpeg、Pandoc 两个可选组件，更新日志在安装向导的“更新日志”页面查看。
